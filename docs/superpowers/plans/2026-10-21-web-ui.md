# Open-fresh Phase 3 — React Web UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the React + Vite + TypeScript Web UI (`frontend/`) covering Planner, Grocery List, Calendar, Cookbook & Review Queue, Kitchen Inventory, Budget & Prices, and Settings, compiled and served by the FastAPI backend on port `4269`.

**Architecture:** `frontend/` is a Vite + React 19 + TypeScript SPA with typed same-origin API helpers (`src/api/client.ts`) and modular feature views (`src/features/*`). `backend/openfresh/app_factory.py` serves the compiled bundle from `OPENFRESH_STATIC_DIR` (or a fallback HTML shell during backend-only test runs) at `GET /` and `/assets/*`, while `backend/Dockerfile` builds the frontend in a `node:22-alpine` stage and copies `dist/` into `/app/static` in the `python:3.12-slim` runtime image.

**Tech Stack:** React 19, TypeScript, Vite, Vitest + `@testing-library/react` + `jsdom`, FastAPI (`StaticFiles`, `FileResponse`, `HTMLResponse`), pytest, Docker multi-stage build.

**Spec:** `docs/superpowers/specs/2026-10-21-web-ui-design.md`

## Global Constraints

- The `openfresh` server listens on port `4269` (`http://localhost:4269/`) and serves both the REST API and the Web UI from the same origin.
- API routes (`/settings`, `/items`, `/inventory`, `/recipes`, `/plan`, `/list`, `/prices`, `/budget`, `/spend`, `/docs`, `/openapi.json`) must take precedence over the SPA static root and must never be shadowed by static file mounting.
- When `OPENFRESH_STATIC_DIR` (or `frontend/dist`) is absent, `GET /` must still return HTTP `200` (`text/html`) with a fallback shell containing `<div id="root">` so backend `pytest` suites pass without requiring a prior Node build.
- All unit and component tests (`pytest` in `backend/` and `vitest run` in `frontend/`) must run offline using mocked `fetch` / `TestClient`.
- Modals and interactive controls must use accessible semantic HTML (`<dialog>`, `<nav>`, `<main>`, `<label>` associations).

## Review Focus

1. **Static mount shadowing API routes** — mounting `StaticFiles` at `/` directly in FastAPI shadows or breaks `POST`/`PATCH`/`DELETE` API routes if registered improperly; `include_router(build_router(...))` must be registered first, `/assets` mounted specifically, and `GET /` registered as an explicit route. Pinned by `test_root_serves_web_ui_html_without_shadowing_api` (Task 1).
2. **Invalid date range on `GET /plan`** — calling `GET /plan?start_date=not-a-date&end_date=2026-10-31` or `start_date > end_date` must return HTTP `422` rather than a 500 error or empty silent failure. Pinned by `test_get_plan_date_range_and_validation` (Task 1).
3. **Grocery list "Complete Shopping" with multiple checked items** — checking off items on the Grocery List with a chosen storage location (`pantry` / `fridge` / `freezer`) and clicking "Complete Shopping" must call `POST /inventory` for each checked item and refresh the list. Pinned by `test_grocery_list_complete_shopping_adds_to_inventory` (Task 2).
4. **Clearing `needs_review` from the Review Queue modal** — editing a flagged recipe in `CookbookView` and clicking "Save & Mark Reviewed" must send `PATCH /recipes/{id}` with `needs_review: false, review_notes: null` and remove it from the Review Queue tab. Pinned by `test_cookbook_ingest_and_review_queue_resolve` (Task 3).
5. **Kitchen inventory `+` / `−` stepper boundary at zero** — clicking `−` on an inventory item in `KitchenView` must call `PATCH /inventory/{id}` with `{"delta": -1}` and update the displayed quantity. Pinned by `test_kitchen_inventory_tabs_and_steppers` (Task 3).

  - `planner.get_range(conn: sqlite3.Connection, start_date: str, end_date: str) -> list[dict]` — returns all `plan_entries` with `date >= start_date AND date <= end_date` joined with `recipes.title`, ordered by `date, plan_entries.id`.

  - `app_factory.create_app(db_path: str | None = None, static_dir: str | None = None) -> FastAPI` — registers `build_router(get_conn)` first, mounts `/assets` from `static_dir` (or `OPENFRESH_STATIC_DIR`, `/app/static`, `<repo>/frontend/dist`) when present, and serves `index.html` (or a `200 OK` fallback HTML shell containing `<div id="root">`) at `GET /`.
